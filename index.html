Follow the work across files.

01 / READ

From project notes to references

Read Markdown with tables, diagrams and formulas, then follow local links to related files. Keep PDFs, images, supported Office documents and ebooks in adjacent tabs.

02 / INSPECT

From a chart to its records

Expand JSON trees, read CSV/TSV tables and browse read-only SQLite snapshots. Inspect complete values, filter records and check schema while leaving the source database unchanged.

03 / EDIT

Check the source. Fix the text.

Switch to source to fix a typo or configuration value. Existing UTF-8 files save automatically, with explicit ⌘S available. ⌘N starts an untitled note; its first save asks for a location.

The same folder. The underlying data.

Choose a table or view, search all records across every column and sort results, or double-click a cell to read its full value. SQLite uses a private read-only snapshot.

Start with files you already have.

⌘O opens a file; ⌘⇧O opens a folder. Browse related files in the sidebar and find files by name or path in title-bar search. Supported readers let you switch between preview and source.

Opening, editing, saving and recovery ↗ · Full formats and compatibility ↗

Office layout and media codecs depend on macOS. Spreadsheet formulas show saved values without recalculation. Some formats provide partial previews. Markdown remote images and HTML network content can connect to the internet; optional usage telemetry is controlled in Settings.

Installers, release notes & SHA-256 checksums ↗

  1. Choose an installer from the latest release: macos-arm64 for Apple Silicon (M-series), or macos-x86_64 for Intel.
  2. Open the DMG and drag Glim into Applications.
  3. Downloads are ad-hoc signed and not Apple-notarized. If blocked, try opening once, confirm the download source, then use System Settings → Privacy & Security → Open Anyway. You do not need to disable system security.

Configured releases support signature-verified in-app updates. Update signatures and Apple notarization are separate.
