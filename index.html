Documents and data, too

Keep PDFs, images, supported Office documents, ebooks and code in adjacent tabs. SQLite uses a separate read-only snapshot for browsing schema, filtering and sorting records.

Know what to expect

Table, tree, image and document previews focus on reading. Ordinary UTF-8 source supports basic editing and saves automatically to the original file. Office layout can differ; spreadsheet formulas show saved values without recalculation.

Files open locally. Markdown remote images, HTML network resources, updates and enabled usage statistics can use the network. Usage statistics can be disabled in Settings.

Install Glim

Download for Mac

Release notes and SHA-256 checksums are on the Release page.

  1. Under Assets in the latest Release, choose macos-arm64 for Apple Silicon (M-series) or macos-x86_64 for Intel.
  2. Open the DMG and drag Glim into Applications.
  3. The app is ad-hoc signed and not Apple-notarized. If blocked, confirm the download is from the official Release, try opening once, then choose System Settings → Privacy & Security → Open Anyway. Keep system security enabled.

Once installed, press ⌘O for a file or ⌘⇧O for a folder.
