# Glim website

Official website: https://glimapp.github.io/

Static English/Chinese landing page hosted by GitHub Pages from `main` at the repository root. Edit `index.html` to update copy or styling. Downloads always link to the latest GitHub Release; app update feeds remain signed release assets in `glimapp/glim`.

Assets reference the main Glim repository. No build step, third-party scripts, analytics or cookies. Language preference is stored locally in the browser.

官网为中英双语静态页面，由 GitHub Pages 从 `main` 根目录部署。编辑 `index.html` 即可更新。下载入口指向最新 GitHub Release；自动更新源保留在主仓库签名发布附件中。
