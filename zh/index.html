使用前了解这些边界

表格、树、图片和文档预览以阅读为主；普通 UTF-8 原文支持简单编辑，并会自动写回原文件。Office 排版可能与原应用不同，电子表格显示已保存的公式结果，不重新计算。

安装 Glim

下载 Mac 版

版本说明和 SHA-256 校验值均在 Release 页面。

  1. 在最新 Release 的 Assets 中选择安装包：M 系列芯片选 macos-arm64，Intel 选 macos-x86_64。
  2. 打开 DMG，将 Glim 拖入“应用程序”。
  3. 应用采用临时签名，尚未经过 Apple 公证。如被拦截，确认下载来自官方 Release，尝试打开一次，再到“系统设置 → 隐私与安全性”选择“仍要打开”。无需关闭系统安全保护。

安装后按 ⌘O 打开文件，或按 ⌘⇧O 打开文件夹。
